# Contributing to Boop Android

## Development Setup

1. Clone the repo
2. Run npm install
3. Connect Android device with USB debugging
4. Run npx react-native run-android

## Code Style
- TypeScript with strict types
- Functional components with hooks
- Services in src/services/, screens in src/screens/

## Pull Requests
1. Fork and branch from main
2. Make changes, test on a real device
3. Open a PR with clear description
